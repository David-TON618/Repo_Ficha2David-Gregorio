# Ficha 5

A aplicação da Ficha 5 parte da coleção criada na ficha anterior. Foi acrescentado um formulário para inserir cartas.

## Como executar

Na pasta `server`, executa `npm install` e `npm run dev`.

Na pasta `client`, executa `npm install` e `npm run dev`.

O servidor fica em http://localhost:3000 e a aplicação React em http://localhost:5173.
